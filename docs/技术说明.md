# EMG / 电容 / 静电计多通道采集软件

Windows 桌面程序，可在主页切换三种板卡：

- 肌电 EMG：8 通道电压波形。
- 电容：35 个测量通道和 5 个参考通道，共 40 通道原始值。
- 静电计：8 通道电流、电荷和电压信号；CH1 支持 nA、μA、mA 三档。

三种模式都支持分通道波形、全部通道叠加图、独立通道显示/导出开关、设备状态、丢包统计、CSV 录制、板卡 Wi-Fi 连接、恢复原 Wi-Fi和按需配置 Windows 防火墙权限。软件持续检测当前 Wi-Fi：连接 `WNZL_Emg` 时自动切到 EMG，连接 `ESP32_Pcap35` 时自动切到电容，连接 `WNZL_Emeter8` 时自动切到静电计。连接时不依赖热点扫描结果，先直接连接当前模式对应板卡，失败后依次尝试另外两块板卡。通道区提供“全选、反选、全不选”，没有通道分组预设。

## 使用方法

1. 在“采集类型”中选择 EMG、电容或静电计。
2. 软件启动时只读取并显示当前 Wi-Fi，不会主动连接网络。点击“连接板卡 Wi-Fi”后，软件先直接连接当前模式对应的板卡；若连接失败，再依次尝试另外两块板卡。连接成功后自动切换到对应模式。软件新建的板卡 Wi-Fi 配置采用手动连接方式，避免 Windows 因配置文件而自行连接。

板卡热点连接成功后，软件最多等待 30 秒获取协议要求的本机地址 `192.168.4.2`，等待期间不会提前判定失败或切换到另一块板卡。

连接过程中“暂停连接”按钮会启用。点击后立即停止软件的当前等待和后续板卡尝试；已经发给 Windows 的连接请求不会被强制断开，避免破坏刚建立但仍在获取地址的连接。
3. 确认采样率与板卡固件一致。EMG 默认 `1000 Hz`；电容默认每通道 `100 Hz`；静电计默认 `1000 Hz`，资料也标注支持 `2000 Hz`。静电计 CH1 档位必须与板上拨码一致；其 UDP 端口默认 `8060`，部分板卡可改为 `8080`。
4. 点击“开始采集”。无板卡时可以勾选“演示信号”检查界面和导出。
5. 按需打开或关闭通道。开关同时控制两种波形页面和下一次 CSV 录制的列。
6. 点击“开始录制”选择 CSV 路径。录制期间通道开关会锁定，避免 CSV 列中途改变。
7. 停止采集后可以点击“恢复原 Wi-Fi”。

软件每 2 秒读取一次当前 Wi-Fi，但只用于识别模式，不会主动连接或切换网络。连接逻辑不要求板卡先出现在 Windows 热点扫描列表中。点击连接按钮、开始真实采集，或在 Windows 网络菜单中手动连接板卡热点后，软件都会切换到对应采集模式。若采集中途手动连接到另一种板卡，软件会先停止当前采集和录制，再切换模式，避免不同协议的数据写入同一个文件。切换到板卡热点后，电脑暂时不能通过该无线网卡访问互联网，这是板卡热点不提供互联网造成的正常现象。

分通道页面只排列当前打开的通道，并根据数量自动调整每行高度。每行最小 `54` 像素、最大 `180` 像素；通道较少时波形会自动放大但不会过高，通道较多时页面可以滚动查看。

首次真实采集时，软件会检查 Windows 防火墙入站权限。经用户确认和一次管理员授权后，会同时创建 EMG `8060` 和电容 `8080` 两条 UDP 规则，并同时覆盖专用网络和公用网络，避免 Windows 网络类型变化后再次收不到数据。规则只允许来源 `192.168.4.1`，不开放其他来源或端口；演示信号不需要该权限。

## EMG 协议

- UDP，本机地址 `192.168.4.2`，端口 `8060`。
- 帧头：`5A 5A 5A 5A`。
- 16 位小端布局字段：低 4 位是通道数，高 12 位是每通道采样点数；`08 08` 表示 8 通道、每通道 128 点。
- 16 位小端包计数器，`65535` 后回到 `0`。
- 32 位 CRC 字段目前不使用。
- AD 数据为小端有符号 16 位整数；先排列 CH1～CH4 的 128 组采样，再排列 CH5～CH8 的 128 组采样。
- 电压：`原始有符号整数 / 3276.8` V。
- 帧尾：`0D 0A 0D 0A`。
- 标准包长度：`2064` 字节。

## 电容协议

- 标称电容测量范围：`0～约 1.5 nF`。
- 每通道采样率：`100 Hz`。
- UDP，本机地址 `192.168.4.2`，端口 `8080`。
- 帧头：`5A 5A 5A 5A`。
- 通道数：16 位小端整数 `40`。
- 每包采样次数：16 位小端整数 `10`。
- 包计数器：32 位小端无符号整数。
- 每个数据值：32 位小端无符号整数。
- 数据按采样次数优先排列；每次依次为：`REF1, PC1～PC7, REF2, PC8～PC14, REF3, PC15～PC21, REF4, PC22～PC28, REF5, PC29～PC35`。
- 帧尾：`0D 0A 0D 0A`。
- 标准包长度：`1616` 字节。

厂家说明书中的 LabVIEW 曲线纵轴标为 `Cap(pF)`，示例导出保留三位小数，而 UDP 协议使用 `uint32` 整数。因此软件按 `电容值_pF = 原始值 / 1000` 显示和导出，并保留三位小数。5 个参考通道在界面中以黄色标签和虚线显示。

分通道图和全部通道叠加图的纵轴均显示单位及刻度数值：EMG 使用 `V`，电容使用 `pF`。

## 静电计模式

- 8 通道，资料标注采样率支持 `1 kHz / 2 kHz`，默认 `1 kHz`。
- 本机地址 `192.168.4.2`，UDP 默认端口 `8060`，部分板卡使用 `8080`。
- CH1：直流/交流电流，界面可选择 nA、μA、mA 档；导出单位统一为 `μA`，倍率依次为 `×1`、`×1000`、`×1000000`。
- CH2：电荷，`×10`，单位 `nC`。
- CH3：电流，`×1`，单位 `μA`。
- CH4：电流，`×0.1`，单位 `μA`。
- CH5：电流，`×0.01`，单位 `μA`。
- CH6～CH8：电压，`×1`，单位 `V`。

静电计使用与 EMG 相同的 8 通道、128 点、小端有符号 16 位数据帧，再应用上述倍率。静电计分通道图分别显示 `μA / nC / V`；叠加图因物理量不同标记为“混合单位”。

## CSV 字段

- EMG：`接收时间,相对时间_s,所选通道电压_V`
- 电容：`接收时间,相对时间_s,所选通道电容_pF`
- 静电计：`接收时间,相对时间_s,所选通道物理量_单位`

CSV 不写入包计数、状态或其他协议字段。接收时间根据数据包到达时间和输入的采样率回推；相对时间从本次录制的第一个采样点开始。当前三种模式都没有使用设备端时间戳。

## 校验规则

程序严格校验包长、帧头、帧尾、通道数和采样点数。格式不符的数据包计入“无效包”，不会进入波形或 CSV；16 位 EMG 和 32 位电容包计数均支持正确的溢出回绕统计。
